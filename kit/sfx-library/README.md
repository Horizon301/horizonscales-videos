# Sound effect library (CC0 only)

Real recorded sound effects for `kit/skills/real-sfx` (RUNBOOK 3c). **Every file here must be CC0** (public domain: free for paid work, no credit needed).

- Put sounds in sub-folders by kind: `whoosh/`, `hit/`, `pop/`, `click/`, `ding/`, `phone/`, `door/`, `typing/`, `cash/`, `ambience/`, and so on.
- Log every file in `SOURCES.txt` (file | title | creator | license | link). The `cc0-sound-effects` skill writes this for you.
- Downloads from the sound hosts are blocked in the cloud sessions, so new sounds are added from Kai's PC with Claude Code and pushed.

While this folder holds no audio files, the nightly run keeps its current sound (RUNBOOK 3b) and skips real-sfx.
