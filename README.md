# Horizon Scales videos

Finished short videos for [Horizon Scales](https://horizonscales.com), stored here so the scheduler (Metricool) can fetch each file by link.
One folder per video: `videos/YYYY-MM-DD-name/` with `video.mp4`, `cover.jpg` and `brief.md`. `kit/` is the toolkit, `work/` the source of each video, `RUNBOOK.md` the nightly procedure, `log.md` the list of videos.
